Privacy Policy – AIChainVerse Publisher

Last updated: 23 November 2026

AIChainVerse Publisher is a private tool used by the owner of the AIChainVerse Facebook Page to publish the Page's own videos, reels, images, captions and comments through the Meta Graph API. It is not offered to the public and has no login for other users.

What data the app uses

The app only uses an access token for the AIChainVerse Page, issued to the Page's owner. It uses that token to upload the Page's own content and to read the publishing status of those posts. It does not collect, store or process personal data about anyone who views, likes, comments on or follows the Page.

What data the app does not use

  • It does not use Facebook Login for other people.
  • It does not read, store or analyse other users' profiles, messages or comments.
  • It does not sell, share or transfer any data to third parties.
  • It does not use cookies or tracking on this website.

Data deletion

Because the app does not collect data about other people, there is no user data to delete. If you believe the app holds any data about you, send a message to the AIChainVerse Facebook Page and it will be reviewed and deleted.

Changes

If this policy changes, the updated version will be posted on this page with a new date.

Contact

Questions about this policy: message the AIChainVerse Facebook Page.
